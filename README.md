## 介绍

简单来说就是一个Windows桌面组件的容器，为了方便于第三方开发，我使用了WebView组件作为窗口容器（可能牺牲了一些性能作为代价），它支持一些不同场景的组件展示，比如悬浮组件（类似于弹幕，提供了点击穿透能力），置顶组件（比如置顶的便签），以及桌面组件（可以开发一些番茄钟或者其他东西）

## StickyNote 桌面便签（Go + walk）

- 从零搭建 Windows 桌面便签：文字展示/编辑、窗口置顶、防抖自动保存、位置尺寸记忆。
- 技术选型：`github.com/lxn/walk`（Win32 原生控件，纯 Go，无 CGO/前端工程）；置顶走 `win.SetWindowPos(HWND_TOPMOST)`，walk 本身无此 API。
- 按要求改为 DDD 分层：`internal/domain/note`（聚合根 Note + Bounds 值对象 + Repository 接口）、`internal/application/noteapp`（用例编排 + View DTO）、`internal/infrastructure/persistence`（JSON 原子写仓储）、`internal/interfaces/desktop`（walk 窗口）、`cmd/stickynote`（组合根）。
- 资源清单：`cmd/stickynote/app.rc` 经 MinGW `windres -O coff --target=pe-x86-64` 编译成 `rsrc.syso`（rsrc@latest 拉取失败，改用 windres）。
- 数据/日志：`%AppData%\StickyNote\note.json`、`app.log`。
- 实测占用（空闲 10s）：工作集 22.5 MB，私有内存 15.7 MB，CPU 增量 0.000s，9 线程 / 263 句柄；exe 6.06 MB。
- 坑：测试时用 WScript SendKeys 输入，焦点落在复选框上导致空格把"窗口置顶"勾上了（不是代码 bug）；已加 `editor.SetFocus()` 让启动焦点落在编辑框。
- 单测：domain 与 persistence 共 8 个用例，`go test ./...` 全绿。

- **坑 3**：storage.googleapis.com 直连被拒，改用 `storage.flutter-io.cn` / `pub.flutter-io.cn` 镜像（环境变量仅在单条命令内 export，未写入系统）。
- 环境变更（已获同意）：Flutter SDK 3.47.8 便携解压到 `C:\Users\zq265\.workbuddy-ai\binaries\flutter`（3.1G），pub 缓存 `%LOCALAPPDATA%\Pub\Cache`（575M）；未改 PATH、未写注册表、未装 VS Build Tools，因此编不出 Windows exe。
- 磨砂背景（亚克力）需求：用户希望便签复用 TranslucentTB 的能力。核查结论——TTB 是注入 explorer.exe 的进程内插件，只对 `Shell_TrayWnd`/`Shell_SecondaryTrayWnd` 调 `SetWindowCompositionAttribute`，没有对第三方应用开放注册接口，也不会枚举其他窗口，因此不可能作用到便签窗口。用户明确要求「不能就算了」，已放弃该分支（`feature/acrylic` 已删，试验代码留在 `stash@{0}` 存档，未合入）。
- 若将来要做磨砂，正确路径是应用自己 opt-in：Win11 22H2+ 用 `DWMWA_SYSTEMBACKDROP_TYPE`(38)=3(Acrylic)/2(Mica) + `DwmExtendFrameIntoClientArea(-1)`，Win10 回退 `SetWindowCompositionAttribute` ACCENT_ENABLE_ACRYLICBLURBEHIND；关键是客户区不能画实底（walk 用 `TransparentBrush{}` → BS_NULL 画刷）。系统级"给所有窗口加磨砂"只能靠 DWM 注入类工具（DWMBlurGlass 等），非 TTB。
